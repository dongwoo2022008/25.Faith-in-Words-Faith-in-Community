## Provenance of the design note

The design note that Section 4.1 of the manuscript refers to is `06_planning_docs/work_order_LC_religious_signals_2026-09-17.md`. Three records date it. This repository's first commit is d1901f6 of 2026-09-19 05:28 UTC (14:28 KST) and the note was committed in a07732a at 09:12 UTC (18:12 KST) the same day, among 201 commits made on 19 September, so GitHub's own timestamps show the note existed by then. Earlier still, the note was saved as a document in the author's Claude project "신앙과학문" with a server creation timestamp of 2026-09-17 23:37 UTC (2026-09-18 08:37 KST), and the same file sits in the Google Drive folder named above, whose version history Google keeps. The run log of the confirmatory estimates, `02_results/run_log_2026-09-18.md`, refers to the note as the "work order (revised 2026-09-17)". The exploratory first pass that preceded it is `06_planning_docs/religious_language_first_analysis_2026-09-05.md`.

Paths inside the step scripts refer to the container they were run in (`/mnt/user-data/uploads/...`, `out/`); point them at `04_data/` before running. Random seeds are fixed in each script. The LLM coding prompt is `02_results/coding_validation/CODEBOOK.md` and the record-level output is `02_results/coding_validation/llm_coding_lc_820.csv` (the version with the loan texts is on the Drive copy). The coders, as stated by the author and recorded in Appendix B1 of the manuscript: primary coder Claude Fable 5.1 (Anthropic, model ID claude-fable-5-1), run as twelve parallel instances in the Claude application on 18 September 2026, each reading a disjoint share of the 820 records (the application exposes no sampling temperature or other decoding settings); second coder Claude Opus (Anthropic), same application, date and settings, on the stratified 200-record validation sample. The raw LendingClub (Kaggle distribution of the 2018Q4 release) and Prosper (Kaggle distribution) files were downloaded in June 2026.

## What is not in the repository

Raw loan data (LendingClub 392 MB, Prosper 86 MB) exceed GitHub's file-size limit and are public on Kaggle (`04_data/raw/raw_data_location.md`). The docx and pdf builds, the six figure PNGs, the external data files, the coding spreadsheets and the coding-result CSVs with loan texts are on the Google Drive folder `논문.김동우/Under.writing/25.Faith in Words, Faith in Community`, which mirrors this layout with Korean folder names; the figure PNGs and the PDF of the current manuscript will be added to the archived release. The figures can be regenerated from the scripts in step 4 above.

The study began in September 2026 as a feasibility review that also looked at two Korean platforms (Moneyauction and Popfunding); `06_planning_docs/religious_language_P2P_text_data_review.md` and `religious_language_first_analysis_2026-09-05.md` record that stage. The paper uses none of that material. Files holding Korean-platform borrower texts or their coding (a context-sample appendix, a PF validation answer key, a PF inter-AI reliability sheet, and the PF entries of three agreement files) were removed from this repository on 16 October 2026 because they were not part of the paper and contained personal narratives; they remain in the repository's history before that date, and the author intends to purge them from the history before the archived release. Code paths that mention a `pf` sample (`step7_kappa.py`, `preprocessing_exploration/coding_sheet.py`) are inert without those files.

Two scripts were lost when the working environment was reset in October 2026 and are not in `03_code/`: the one behind `stepC_economic.json` (sub-grade-year cell default and net-loss comparison, Section 6.3) and the one behind `stepR_review_extras.json` (CEM within the eight stable occupations, Table 3). Their outputs are included. The first computation has since been reproduced exactly in `03_code/analysis/run_v19_extras.py` (net loss = default × (1 − total payments / funded amount); the "mean life" in `stepC_economic.json` is the mean contractual term); the second is described in the Table 3 notes and will be rewritten from that description if a reviewer asks for it.
