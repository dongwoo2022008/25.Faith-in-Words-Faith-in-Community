## Reproduction

1. `03_code/preprocessing_exploration/lc_extract.py` → `lc_final.pkl` (terminated LendingClub loans, cleaned variables; status as of the 2018Q4 release)
2. `03_code/analysis/step1.py` → `T.pkl` (terminated sample, 1,344,976 loans), `D.pkl` (description sample, 123,292), religious indicators and the six text dictionaries
3. Tables: `step2.py` (H1 baseline and period split, Table 2), `step3.py` (stable occupations and CEM, Table 3), `stepN_neighbor.py` (neighbor occupations, Table 3 Panel B), `step5c.py` (entropy balancing, Table 2 column 5, Appendix C1), `step4.py`, `step4b_embed.py`, `step4d_rep.py` (H2 double machine learning, Tables 6–7, Appendix C5), `step3b_fakedict.py` (random-word permutation, Appendix Figure C1), `step7_kappa.py` and `kappa_after_human_coding.py` (coding agreement, Appendix B1), `stepH_precision.py` (indicator audit, Appendix B2), `stepID2.py` (Oster and Cinelli–Hazlett, Table 4), `step7a.py` (Prosper replication, Table 5), `stepR2a.py` (clergy and staff split, tenure interaction, Tables 10 and C4), `stepA_arda.py` (local religiosity, Table 11, Appendix A2), `stepU_unemp.py` (unemployment shocks, Appendix C6), `step6.py` (discrete-time hazard, Appendix A1), `stepG_extras.py` (selection into writing a description, alternative clustering, Appendix C2–C3), `step7b.py` (investor-side funding measures, Section 6.3). The sub-grade-year cell comparison of Section 6.3 is in `estimates_json/stepC_economic.json` (its computation is reproduced exactly by `run_v19_extras.py`) and the CEM-within-stable-occupations row of Table 3 in `estimates_json/stepR_review_extras.json`; the two scripts that produced these files were not preserved (see below)
4. Figures: `03_code/fig_framework.py` (Figure 1), `03_code/analysis/figures/fig2_grouped_v16.py` (Figure 2; `fig2_grouped_v13.py` is the earlier version with the column (2) label "2008–2014"), `fig3_dml_v13.py` (Figure 3), `fig4_density_v13.py` (Figure 4), `fig5_cumdefault_v13.py` (Figure 5), `figC1_permutation_v13.py` (Appendix Figure C1). All read `estimates_json/` or the step outputs, not the raw data.
5. Verification scripts (October 2026): `verify_rate_schedule.py` (distinct rates within issue month × sub-grade × term, Section 6.3), `verify_vintage_default.py` (descriptions and default rates by issue year), `verify_recovery.py` (post-charge-off recoveries, an analysis dropped from the paper)
6. `03_code/manuscript_build/build_v19.py` → docx/pdf (pandoc, python-docx, LibreOffice); `selfcheck.py manuscript_v19.md` runs the style checks.

Paths inside the step scripts refer to the container they were run in (`/mnt/user-data/uploads/...`, `out/`); point them at `04_data/` before running. Random seeds are fixed in each script. The LLM coding prompt is `02_results/coding_validation/CODEBOOK.md` (the record-level output is in the coding CSVs on the Drive copy). The coders, as stated by the author and recorded in Appendix B1 of the manuscript: primary coder Claude Fable 5.1 (Anthropic, model ID claude-fable-5-1), run as twelve parallel instances in the Claude application on 18 September 2026, each reading a disjoint share of the 820 records (the application exposes no sampling temperature or other decoding settings); second coder Claude Opus (Anthropic), same application, date and settings, on the stratified 200-record validation sample. The raw LendingClub (Kaggle distribution of the 2018Q4 release) and Prosper (Kaggle distribution) files were downloaded in June 2026.

## What is not in the repository

Raw loan data (LendingClub 392 MB, Prosper 86 MB) exceed GitHub's file-size limit. Binary files (the docx and pdf builds, the six figure PNGs, the external data files, the coding spreadsheets and the two large coding-result CSVs) could not be pushed through the interface used to maintain this repository. All of them are in the Google Drive folder `논문.김동우/Under.writing/25.Faith in Words, Faith in Community`, which mirrors this layout with Korean folder names. The figures can be regenerated from the scripts in step 4 above.

Two scripts were lost when the working environment was reset in October 2026 and are not in `03_code/`: the one behind `stepC_economic.json` (sub-grade-year cell default and net-loss comparison, Section 6.3) and the one behind `stepR_review_extras.json` (CEM within the eight stable occupations, Table 3). Their outputs are included. The first computation has since been reproduced exactly in `03_code/analysis/run_v19_extras.py` (net loss = default × (1 − total payments / funded amount); the "mean life" in `stepC_economic.json` is the mean contractual term); the second is described in the Table 3 notes and will be rewritten from that description if a reviewer asks for it.
