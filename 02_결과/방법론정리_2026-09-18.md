# 논문에 적용된 방법론 정리 (2026-09-18 기준, 실행 완료분)

논문의 모수는 예측 정확도가 아니라 두 신호(종교기관 소속, 서술문 종교 언어)의 부분 효과와 그 방향이다. 방법론은 (1) 확인적 검정, (2) 대안 설명 차단, (3) 기제 좁히기, (4) 측정 타당성의 네 층으로 구성되며, 각 방법이 무엇을 배제하고 무엇을 배제하지 못하는지를 본문에 명시한다.

## 1. 자료 구축
- LendingClub 2007–2018Q4 공개 파일(2,260,701건) → 종결대출(Fully Paid/Charged Off/Default) 1,344,976건; 서술문 보유 하위표본 123,292건(2008–2014).
- 외부 결합: ARDA 2010 종교 센서스 카운티 파일(신자율·교회 수), Census ZCTA–카운티 관계표, BLS LAUS 카운티 실업률 2008–2018. ZIP3 단위 인구가중 결합(894개 지역, 결합률 99.97%).
- Prosper 공개 파일(113,937건) → 종결 50,270건, 직업 코드 Clergy/Religious 141건. H1 교차 재현용.

## 2. 변수
- 종속: 부도(Charged Off·Default = 1).
- 처치 1 — 종교기관 소속(religious-institution affiliation): 직업란 정규식. 성직 역할어(pastor, minister, chaplain, priest, rabbi, missionary, …) 또는 종교 조직어(church, parish, congregation, …; 병원·학교·보험·은행명 제외). 종결 표본 3,131건(성직 2,363 + 비성직 교회 직원 768).
- 처치 2 — 서술문 종교 언어: 명시 사전(God, Jesus, Christ, church, pray, bless, faith[종교 용법], Lord, Bible, tithe, ministry, amen, 교단명; "faith in me", "Lord & Taylor" 등 관용 제외). 681건. 코더 검증 지표(오탐 제외) 583건.
- 통제: 등급, 발행연도, 금리, FICO 중앙값, log 소득, DTI, 60개월, log 금액, 근속, 주거, 소득검증, 용도, 주(state) 고정효과. 서술 모형 추가: log 서술 길이 + 6개 텍스트 사전(도덕·곤경·감사·가족·도움요청·사업).

## 3. 확인적 검정 (사전 지정, 2개만)
- 로짓, 주 클러스터 SE, Newton(미수렴 시 BFGS) 수렴 확인. OR와 평균한계효과(AME) 병기.
- H1 소속 OR < 1, H2 종교 언어 OR > 1. 단측, Holm 보정.
- H1 표본: 소속 전건 + 무작위 대조 25만(메모리 제약, 설계 아님).
- 판정 규칙을 결과 전에 문서화(작업지시서 2026-09-17): H2가 텍스트 표현 조건화 DML에서 CI가 0을 포함하면 하향, H1이 안정 직업군 통제 후 0.85 이상이면 해석 격하.

## 4. 대안 설명 차단 (강건성)
| 반론 | 방법 | 배제하는 것 / 못 하는 것 |
|---|---|---|
| 안정적 직업 일반 효과 | 8개 안정 직업군 더미 동시 투입; 안정 직업군 내 비교 | 공공·기관 고용 일반 효과 배제 / 종교 기관 고유의 고용 조건은 미배제 |
| 신용 프로필 차이 | 엔트로피 균형화(76개 모멘트 정확 일치, Hainmueller 2012) | 관측 공변량 분포 차이 배제 / 미관측 배제 못 함 |
| 비선형·상호작용 누락 | 이중 기계학습 DML-PLR(Chernozhukov et al. 2018), CatBoost 뉴이선스, 5-fold cross-fitting; 희귀 처치에서 IRM-ATE trimming 인공물 확인 후 PLR·ATTE 사용 | 함수형 오설정 배제 / 미관측 배제 못 함 |
| 서술 길이·문체 대리 | log 길이·길이 10분위 FE; 등급×연도 내 길이 최근접 1:5 매칭; 6개 텍스트 사전 순차 투입 | 길이·감사·곤경·도덕 언어 대리 배제 |
| 텍스트 전체 정보와 중복 | DML 뉴이선스에 TF-IDF-SVD100 / spaCy 300d 단어벡터 / doc2vec100 투입 | 선형 사전이 놓친 텍스트 정보 통제 → H2 정밀도 부족 확인(하향) |
| 아무 단어 집합이나 되는가 | 가짜 사전 순열 1,000회(종교 어휘 제외, 빈도 일치 무작위 단어 집합), 잔차화 LPM | 우연한 단어 집합 효과 배제(p 0.005) |
| 미관측 교란 | Oster(2019) δ(Rmax=1.3R²), Cinelli–Hazlett(2020) RV, 벤치마크 = 근속·소득검증 | 인과 주장 대신 "얼마나 강한 교란이 필요한가" 수치화 |
| 단일 플랫폼 | Prosper H1 재현(직업 코드), 플라시보 직업 동시 투입 | 플랫폼 특수성 배제 |
| 지역 종교성의 대리 | ARDA 신자율·교회 밀도 통제 | 지역 효과 배제 |
| 예측력 주장 | 5-fold CV AUC, ΔAUC 부트스트랩 | ΔAUC ≈ 0 확인 → 예측 개선 주장 안 함 |

## 5. 기제 좁히기 (확인적 아님, 각각 "일치하는 패턴"으로만 서술)
- 동일 기관 내 대조군: 성직 vs 비성직 교회 직원. 두 OR 동일(0.67/0.68) → 소명·서약이 아니라 소속.
- 이질성을 통한 식별(Rajan–Zingales형): 소속 × 교회 밀도 상호작용, 주 FE 및 ZIP3 FE(601개) 하에서 유의 → 지역 고정 특성으로 설명 안 되는 조절.
- 노동시장 충격 반응: 소속 × 대출 기간 중 실업률 상승(BLS) 무의미; 교사·공무원 양성 대조도 무의미 → 검정력 한계 병기.
- 종교 언어의 무조절: 종교성·교회 밀도와 상호작용 없음 → cheap talk 해석과 정합.
- 하위 유형: 코더 코딩으로 관용구/정체성/실천 분리; 실천 보고(82건)는 부도와 무관.
- 시점: 이산시간 hazard(cloglog, 대출–월 패널, 부도 시점 = 최종 납부 + 4개월 근사). 소속 효과는 기간 전체 균일, 종교 언어는 12개월 이후에만.

## 6. 측정 타당성
- 서술 코딩: 코드북(type a/b/c/x, frame) 기반 코더 에이전트 전건 코딩(820건); 다른 모델의 독립 2차 코더로 층화 200건 재코딩, κ 0.86(이분 0.81). 오탐 98건은 자연 플라시보(OR 0.95).
- 측정 완전성: 명시 어휘를 제거한 분류기(TF-IDF + spaCy, CV AUC 0.92)로 미표기 12.2만 건 스크리닝, 층화 판독 → 사전 밖 종교 표현은 수십 건 규모. 사전이 모집단을 거의 포착함을 확인.

## 7. 경제적 크기
- 같은 sub_grade×연도 셀 대비 부도율·순손실(1 − 총상환/실행액) 격차를 만기 기준 연환산: 소속 −64bp/년, 종교 언어 +28bp/년. 가격에 반영되지 않은 정보의 크기로 서술, 거래 가능성 주장 안 함.

## 8. 하지 않은 것과 이유
- 딥러닝 부도 예측 모형: ΔAUC ≈ 0, 논문 모수와 무관.
- 구조방정식·매개분석: 관측 자료에서 순차 무시가능성 가정 불충족; 개인 수준 매개변수 부재; 이미 조절효과로 검정.
- 도구변수·자연실험: 존재하지 않음. 반복 차입자 패널: member_id 전건 결측으로 불가.
- 사람 코더 검증: AI 간 κ로 대체, 심사 요구 시 시행.
